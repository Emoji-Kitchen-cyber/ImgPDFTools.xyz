Frequently Asked Questions

Are these tools really free?

Yes — every tool is completely free with no account, no watermarks, and no usage limits.

Are my files uploaded anywhere?

No. All processing happens locally in your browser. Your images and PDFs never leave your device.

Do I need to install anything?

No installation required. The tools run in any modern browser, and many work offline as well.

Which image formats are supported?

ImgPDFTools supports JPG, PNG, and WEBP across its image tools. Some tools also accept GIF and BMP files.

Can I use these tools on my phone or tablet?

Yes. All tools are fully responsive and tested on Android and iOS devices.
