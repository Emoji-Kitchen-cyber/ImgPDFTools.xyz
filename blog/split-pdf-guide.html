Large PDFs are hard to share, slow to email, and frustrating to navigate. Splitting a PDF lets you extract exactly the pages you need — a single chapter, a specific form, or a set of slides — without downloading extra software or uploading sensitive documents to a cloud server.

1. When You Need to Split a PDF

Common use cases include extracting one chapter from a book-length PDF, separating individual invoices from a batch export, pulling out specific pages from a legal document, and sharing only the relevant portion of a report with a client. All of these tasks are handled in seconds with a browser-based splitter.

💡 Tip: If you need to rearrange pages rather than split them, use the PDF Annotator to reorder content, or merge individually extracted PDFs in your preferred order using the Merge PDF tool.

2. Split Modes

  • Split every page — each page becomes its own PDF file, all downloaded as a ZIP archive.
  • Extract a range — enter a range like 2-8 to get pages 2 through 8 as a single new PDF.
  • Extract specific pages — enter individual page numbers like 1,4,7 to pick only the pages you need.
  • Split at intervals — divide a long PDF into equal-sized chunks, for example every 10 pages.

3. Step by Step

  • Upload your PDF — drag and drop or click to select the file.
  • Choose a split mode — select every page, a range, specific pages, or fixed intervals.
  • Enter page numbers if needed — type the range or list of pages you want to extract.
  • Split — click the button to process the file locally in your browser.
  • Download — get the output as a single PDF or a ZIP of multiple PDFs.

All processing uses pdf-lib and runs entirely in your browser. Your PDF is never sent to any server.

4. Tips

  • Check the page count first — open the PDF in a viewer to confirm page numbers before splitting.
  • Use range mode for chapters — it produces one clean PDF rather than many individual files.
  • Combine with Merge PDF — split out sections from multiple documents, then merge them into a new document in any order.
  • Password-protected PDFs — remove the password first using a PDF unlock tool before splitting.
