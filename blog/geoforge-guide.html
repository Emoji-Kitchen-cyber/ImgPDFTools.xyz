1. What is GeoForge?

GeoForge is a free, browser‑based GIS studio that lets you draw points, lines, and polygons on an interactive map. You can export your work as Shapefile ZIP, GeoJSON, KML, CSV, or DXF — fully compatible with ArcGIS, QGIS, and Google Earth. No software installation required.

2. Drawing Features on the Map

Select a drawing tool (Point, Line, Polygon, Rectangle, or Circle) from the toolbar, then click on the map to place vertices. Double‑click to finish. You can add attributes like name, category, and description to each feature. Real‑time measurement shows distance or area as you draw.

3. Export Formats Explained

  • Shapefile ZIP – .shp, .dbf, .prj bundled for ArcGIS & QGIS
  • GeoJSON – Web mapping standard
  • KML – Google Earth compatible
  • CSV – Spreadsheet with coordinates
  • DXF – AutoCAD compatible
  • TopoJSON – Compact topology format

4. Importing Existing GIS Data

Already have GeoJSON, KML, or CSV files? Upload them directly into GeoForge — all features will appear on the map instantly. You can then edit attributes, modify geometries, and re‑export in any format you need.

5. Real‑World Use Cases

  • Urban planners mapping proposed roads and infrastructure
  • Environmental scientists marking forest boundaries and conservation areas
  • Real estate developers plotting land parcels
  • Students creating geography project maps
  • NGO field workers documenting community resources
  • Surveyors creating quick field sketches
