## 📦 Self-Hosting

Want to host ImgPDFTools on your own server? It's just static files!

### Option 1: Cloudflare Pages (Recommended)

1. Fork this repository
2. Sign up at [pages.cloudflare.com](https://pages.cloudflare.com)
3. Connect your GitHub account
4. Select this repo → Deploy
5. Done! ✅

🔐 Privacy Promise
ImgPDFTools is built on a simple promise: Your files are yours.
• ✅ No file uploads — Everything is processed in your browser using JavaScript
• ✅ No tracking of your files — We literally can't see them
• ✅ No account required — Just open and use
• ✅ No cookies for tracking — Only essential storage (theme, language preference)
• ✅ Open Source — Audit the code yourself
The only analytics we collect is anonymous page-view data (Google Analytics) to understand which tools are popular. We never see your files.
